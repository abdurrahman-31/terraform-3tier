# AWS Two-Tier Infrastructure with Terraform
## Project Overview
**This project uses Terraform to automate the deployment of a secure WordPress infrastructure on AWS. The architecture follows a two-tier design where the web application and database are separated into different network layers. A custom VPC is created with one public subnet for the WordPress web server and two private subnets for the MySQL RDS database. The EC2 instance is automatically configured with Apache, PHP 8.2, and WordPress through a bootstrap script, allowing the application to be ready immediately after deployment. The database is hosted on Amazon RDS within private subnets, ensuring it is not directly accessible from the internet. Security groups control access between the web and database tiers, improving overall security. By defining all infrastructure components as code, Terraform enables consistent, repeatable, and easily manageable deployments while reducing manual configuration efforts.**
